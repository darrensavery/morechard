<p>Your Mentor doesn't send messages on a schedule - it notices things about what you're actually doing (like spending a lot quickly, or letting money pile up without a plan for it) and sends a short, relevant message when that happens. If you keep seeing the same one, it's usually because whatever it noticed is still true - once that changes, the message stops.</p>
