---
title: "[For kids] How do I set up a savings goal?"
---

<p>Tap <strong>New Goal</strong>, give it a name, pick a category, set how much you need, and choose a date you'd like to reach it by. You can have up to 5 goals going at once, so you can save for more than one thing.</p>
