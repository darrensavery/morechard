<p>Morechard doesn't currently ask for or check a child's age or date of birth during setup - it's designed to work for any child old enough to complete simple chores and understand basic saving, which in practice covers a wide age range. A parent creates and manages every child profile, so there's no independent sign-up step a child needs to pass an age check for.</p>
