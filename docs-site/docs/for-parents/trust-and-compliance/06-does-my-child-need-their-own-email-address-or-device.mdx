<p>No email address needed - a child joins using a 6-digit invite code you generate for them, not an email sign-up. Morechard is designed with the assumption that each child has their own device (phone, tablet, or a shared family device set up under their own code), so their chores, goals, and Ledger stay clearly theirs.</p>
