<p>Yes - you can edit a chore's details at any time, as long as it isn't archived. You can't switch a chore between "Photo Proof" and "Skip Approval" if that would conflict with how it's currently set up.</p><p>Deleting a chore archives it rather than erasing it - it stops generating new instances, but every past completion and ledger entry stays exactly as it was. You can restore an archived chore later if you change your mind.</p>
