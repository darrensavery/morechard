<p>For families with more than one parent, analytics on a child's activity only run if <strong>every</strong> parent has opted in and <strong>none</strong> has opted out. In other words, either parent can veto it - if one parent turns analytics off, it's off for the whole family, regardless of what the other parent chose. This is deliberate: neither parent's preference can be overridden by the other.</p>
