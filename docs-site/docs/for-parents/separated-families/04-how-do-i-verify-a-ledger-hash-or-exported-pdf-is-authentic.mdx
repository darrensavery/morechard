<p>Every exported PDF includes a QR code and a document fingerprint. Scanning the QR code (or visiting the verification link and pasting the fingerprint manually) takes you to a public page that recomputes the entire hash chain and confirms whether it's still intact.</p><p>Anyone can use this — a co-parent, a mediator, or a court — without needing a Morechard account, so the document can be checked independently of you.</p>
