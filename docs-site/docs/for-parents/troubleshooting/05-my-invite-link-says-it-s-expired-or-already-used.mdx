<p>Invite codes (for a co-parent or a child joining a device) are valid for 72 hours and can only be redeemed once. If you see this message, the code has either timed out or someone already used it to link a device.</p><p>The fix is simple: go back to the parent dashboard and generate a fresh code, then use that one instead. Sign-in links sent by email work the same way - request a new one if an old one has expired.</p>
