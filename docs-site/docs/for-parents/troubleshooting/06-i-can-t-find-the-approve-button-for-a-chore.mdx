<p>Two common explanations:</p><ul><li><strong>The chore is set to Skip Approval.</strong> If you turned this on when creating it, it pays out automatically the moment your child marks it done - there's nothing to approve, by design.</li><li><strong>Your child hasn't marked it done yet.</strong> A chore only needs your approval after your child has submitted it. If it's still sitting as in-progress on their end, there's nothing for you to approve yet.</li></ul><p>Chores actually awaiting your review show up together on your dashboard - if you expect one there and don't see it, check which of the above applies.</p>
