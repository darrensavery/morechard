---
title: "Is my login secure?"
---

<p>Yes. On the web, your sign-in token is stored in a browser-protected cookie that JavaScript can never read directly. On the phone app, it's stored in your device's secure Keychain (iPhone) or Keystore (Android) — never in plain, readable app storage.</p>
