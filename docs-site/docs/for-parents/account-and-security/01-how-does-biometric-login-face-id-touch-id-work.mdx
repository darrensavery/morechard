---
title: "How does biometric login (Face ID/Touch ID) work?"
---

<p>When you open the app, Morechard automatically prompts for Face ID or Touch ID if you've set it up — no need to tap anything first. A successful check both unlocks the app and refreshes your sign-in, even if your session had technically expired in the background. If biometrics aren't set up, you'll get a PIN pad instead.</p>
