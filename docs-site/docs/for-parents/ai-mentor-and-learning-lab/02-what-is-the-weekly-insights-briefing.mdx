<p>Once a week, per child, you get an AI-written summary of how they've been doing - trends in consistency, responsibility, and planning, compared to the week before. It's generated automatically (with a solid fallback summary if the AI service is briefly unavailable) and only needs to be generated once per week, so it loads instantly after that. It's included with the same plans as AI Mentor.</p>
