<p>Learning Lab is a set of 25 short financial-literacy modules (each roughly 15 - 25 minutes, in four parts: a hook, a lesson, a hands-on activity, and a quiz), spread across four age-appropriate levels. Modules aren't unlocked in a fixed order - they open up based on your child's real activity. For example, reaching a £30 balance unlocks one module; going three weeks without a transaction unlocks another; keeping a goal active with a month-long streak unlocks another.</p><p>Learning Lab is included with the same plans as AI Mentor - it isn't available on Core alone.</p>
